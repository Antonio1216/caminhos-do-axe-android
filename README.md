# Caminhos do Axé — Android

Aplicativo Android para estudo numerológico dos 16 Odus a partir da data de nascimento, com associação editorial de Orixás e campo para anotações pessoais de Exu. A data não determina o Exu pessoal nem o Orixá de cabeça.

### Gerar APK

Abra **Actions → Gerar APK Android → Run workflow**. Na execução concluída, baixe **Caminhos-do-Axe-APK** em **Artifacts**, descompacte e instale **app-debug.apk** no tablet.

O histórico permanece local ao aplicativo. Não contém diagnóstico religioso ou ritual.
